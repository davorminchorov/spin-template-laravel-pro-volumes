#title
The fastest way to ship Laravel like a Pro.

#description
The Laravel Pro template for Spin is a collection of Docker components that helps configure your Laravel project in seconds. Ship often, ship anywhere, ship fast.

#extra
  ::list
  - **Beautiful DX** with an easy onboarding wizard
  - **Zero-downtime deployments** with Docker Swarm + Traefik
  - **Automated deployments** with GitHub Actions
  - **Free SSL certificate** powered by Let's Encrypt
  - **Deploy with any host** that runs Ubuntu 22.04+
  - **Lightning-fast development** with automatically configured Vite
  - **Trusted SSL** for Development
  - **Run powerful services** like Redis, MySQL, and more
  - **Unlimited projects** with a single license
  ::
